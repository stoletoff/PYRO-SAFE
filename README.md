# PYRO-SAFE® — Инженерный калькулятор огнезащитных материалов

Инженерный веб-калькулятор на **Next.js (App Router, TypeScript, Tailwind CSS)** для точного расчета расхода огнезащитных материалов немецкого производителя **«svt Brandschutz»**. Проект оптимизирован для статической генерации (SSG) и автоматического деплоя на **GitHub Pages** через GitHub Actions.

---

## 🚀 Основные возможности

### Модуль 1: Огнезащита кабельных линий (FLAMMOPLAST KS 1)
- **Толщина сухого слоя:** 0,72 мм.
- **Нормативный расход:** 1,73 кг/м² (с учетом технологических потерь).
- **Фасовка:** фирменные ведра по 12,5 кг с автоматическим расчетом целого количества ведер ($\lceil M / 12.5 \rceil$).
- **Формулы расчета площади ($S$):**
  - **Одиночный кабель:** $S = L \times \pi \times d \times N$
  - **Кабели в пучке:** $S = L \times \pi \times d \times 1{,}5$ (с повышающим коэффициентом рельефа)
  - **Лотки с глухим дном:** $S = L \times b \times 1{,}5$
  - **Сетчатые / перфорированные лотки:** $S = L \times b \times 1{,}5 \times 2$ (двусторонняя обработка)
- **Защитный лак PYRO-SAFE SP-2:** Автоматический расчет 0,175 кг/м² при влажности в помещении более 85%.

---

### Модуль 2: Кабельные проходки (UNIVERSALSCHOTT)
- **Геометрия проемов:**
  - Прямоугольные проемы ($H \times W$ мм)
  - Круглые гильзы и проемы ($\varnothing D$ мм)
- **Динамический список кабелей:**
  - Добавление произвольного числа кабельных групп
  - Быстрый выбор типовых марок (ВВГнг-FRLS, АПвПуг, UTP, контрольные кабели и др.)
  - Расчет индивидуального сечения и процента заполнения
- **🚨 Критическая валидация норматива EN 1366-3:**
  - Суммарное сечение кабелей не может превышать **60%** от площади сечения проходки.
  - При превышении 60% расчет немедленно **блокируется**, выводится предупреждение с рекомендациями для проектировщика.
  - Интерактивная шкала заполнения (зеленый / янтарный / красный пульсирующий индикатор).
- **Нормы расхода материалов на 1 м² проема:**
  - **EI 60 (1 слой):** Минплита 1,0 м², KS 1 — 1,65 кг, мастика KS 3 — 3,5 кг, рассыпная минвата — 1,0 кг.
  - **EI 180 (2 слоя):** Минплита 2,0 м², KS 1 — 2,5 кг, мастика KS 3 — 5,0 кг, рассыпная минвата — 1,5 кг.
- **Технологические потери для KS 1:**
  - Нанесение кистью/валиком: **+10%** ($\times 1{,}10$)
  - Безвоздушное распыление: **+30%** ($\times 1{,}30$)
- **Защитный лак SP-2:** 0,175 кг/м² при влажности > 85%.

### Сводная спецификация и экспорт
- Накопление расчетных позиций в ведомость объекта
- Суммарный расчет материалов для отдела снабжения (общее число ведер KS 1, кг мастики KS 3, лака SP-2, м² плит, кг минваты)
- Экспорт спецификации в **Excel / CSV**
- Адаптированная **печать и сохранение в PDF** (`@media print`)

## 💻 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/stoletoff/PYRO-SAFE.git
   cd PYRO-SAFE
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```

4. Откройте в браузере [http://localhost:3000](http://localhost:3000).

## 📦 Сборка и деплой на GitHub Pages

Проект настроен для статического хостинга на GitHub Pages (`stoletoff.github.io/PYRO-SAFE`).

В файле `next.config.ts`:
```typescript
import type { NextConfig } from "next";

const isProd = process.env.NODE_ENV === "production";

const nextConfig: NextConfig = {
  output: "export",
  basePath: process.env.NEXT_PUBLIC_BASE_PATH ?? (isProd ? "/PYRO-SAFE" : ""),
  images: {
    unoptimized: true,
  },
  trailingSlash: true,
};

export default nextConfig;
```

Для проверки статического билда:
```bash
npm run build
```
Сгенерированный статический сайт появится в каталоге `./out`.

### Настройка в GitHub репозитории:
1. Перейдите в **Settings** -> **Pages**.
2. В секции **Build and deployment** выберите **Source: GitHub Actions**.
3. При каждом коммите в ветку `main` пайплайн автоматически проверит линтинг (`npm run lint`), соберет проект (`npm run build`) и опубликует его на GitHub Pages.
